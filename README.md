🌿 AjanjaCare Pharmacy – React Components
A modern, responsive pharmacy landing page built with React and CSS Modules.
Designed for trust, accessibility, and seamless shopping in the healthcare space.
________________________________________
🏥 Overview
AjanjaCare is a healthcare e-commerce demo showcasing prescription management, product categories, and customer trust features.
The project emphasizes clean architecture, responsive UI/UX, and best practices in modern React development.
________________________________________
✨ Highlights
•	📱 Responsive Design – Mobile-first, scales beautifully to desktop
•	🎨 Modern UI/UX – Healthcare-friendly design and branding
•	🧩 Modular Components – Clean, reusable React components
•	♿ Accessible – Semantic HTML + ARIA support
•	⚡ Optimized – Lightweight, fast-loading design
________________________________________
🛠️ Tech Stack
•	React – Component-based architecture
•	CSS Modules – Scoped, maintainable styles
•	Modern CSS – Flexbox, Grid, and responsive utilities
•	HTML5 – Semantic structure
________________________________________
📦 Core Components
Component	Purpose
Header	Branding, navigation, and search
Hero	Banner with primary call-to-action
TrustBadges	Credibility and assurance indicators
ServicesStrip	Key service offerings
FeaturedCategories	Shop-by-category showcase
PrescriptionCallout	Manage prescriptions online
StoreLocator	Find nearby pharmacy locations
InfoTiles	Informational quick-links
Newsletter	Email subscription form
Footer	Links, contact, and legal info

🚀 Getting Started
Prerequisites
•	Node.js (v14+)
•	npm or yarn
Setup
# Clone the repo
git clone <repository-url>
cd ajanajacare-pharmacy

# Install dependencies
npm install
# or
yarn install

# Start dev server
npm start
# or
yarn start
Visit 👉 http://localhost:3000
